# Course Batch Operations Dashboard (Excel)

Tracks seats, enrollments and revenue per batch, flags batches that are full or low on enrollment, and summarises by course.

**What it shows**
- Drop-down course list and a validation rule: Enrolled must be a whole number from 0 up to that row's Seats
- Formulas: Fill Rate, Revenue, and a Status flag (FULL, ON TRACK, LOW ENROLLMENT)
- Dashboard: KPIs, a course-wise table using SUMIF, COUNTIF and COUNTIFS, a chart, and a check cell that confirms totals match
- The low-enrollment cut-off is one editable cell on the Settings sheet

All data is fictional practice data.
